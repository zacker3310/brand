# ATLAS

Design system intelligence: a source-attributed catalog of 100 verified real-world design systems,
their components, tokens, patterns and accessibility guidance, with cross-system comparison.

The application currently lives in [`atlas/`](atlas) (moving to the repository root). Setup, commands
and architecture: [`atlas/README.md`](atlas/README.md), [`atlas/docs/ARCHITECTURE.md`](atlas/docs/ARCHITECTURE.md).
